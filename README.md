# الأكاديمية العربية 🌟
## منصة تعليمية متطورة لتعلم اللغة العربية

![الأكاديمية العربية](./src/assets/arabic-calligraphy.jpg)

### 📖 نظرة عامة

الأكاديمية العربية هي منصة تعليمية تفاعلية مصممة بعناية لتعليم اللغة العربية بأساليب حديثة ومبتكرة. تجمع المنصة بين الأصالة والحداثة في تقديم محتوى تعليمي عالي الجودة يناسب جميع المستويات.

### ✨ المميزات الرئيسية

- 🎨 **تصميم استثنائي**: واجهة مستخدم جذابة مستوحاة من الفن الإسلامي والخط العربي
- 📱 **تجربة متجاوبة**: متوافق مع جميع الأجهزة (الحاسوب، الجوال، التابلت)
- 🎯 **دورات متنوعة**: من الأساسيات إلى المستويات المتقدمة
- 🏆 **شهادات معتمدة**: شهادات إتمام لجميع الدورات
- 💬 **تفاعل مجتمعي**: منصة تفاعلية لتبادل الخبرات
- 🌍 **وصول عالمي**: متاح لجميع أنحاء العالم

### 🛠️ التقنيات المستخدمة

- **Frontend**: React 19.1.0 + Vite
- **Styling**: Tailwind CSS 4.1.7
- **UI Components**: Radix UI + shadcn/ui
- **Animations**: Framer Motion 12.15.0
- **Icons**: Lucide React
- **Charts**: Recharts
- **Package Manager**: pnpm

### 📋 متطلبات النظام

قبل البدء، تأكد من تثبيت:

- **Node.js** (الإصدار 18.0.0 أو أحدث)
- **npm** أو **pnpm** (مدير الحزم)
- **Git** (لإدارة الإصدارات)

## 🚀 دليل التثبيت والتشغيل

### الخطوة 1: تجهيز جهاز الكمبيوتر الخاص بك

#### 1. تثبيت Node.js:
- افتح متصفح الويب الخاص بك واذهب إلى الموقع الرسمي لـ Node.js: [https://nodejs.org/](https://nodejs.org/)
- ستجد زرين للتنزيل، اختر **"Recommended For Most Users" (LTS)**. هذا هو الإصدار المستقر والموصى به.
- قم بتنزيل الملف التنفيذي (عادةً `.msi` لنظام Windows أو `.pkg` لنظام macOS).
- قم بتشغيل الملف الذي قمت بتنزيله واتبع تعليمات التثبيت. في معظم الحالات، يمكنك النقر على "Next" (التالي) حتى النهاية. تأكد من أن خيار "npm package manager" (مدير حزم npm) محدد للتثبيت.

#### 2. تثبيت محرر أكواد (موصى به: Visual Studio Code):
- افتح متصفح الويب الخاص بك واذهب إلى موقع Visual Studio Code: [https://code.visualstudio.com/](https://code.visualstudio.com/)
- قم بتنزيل الإصدار المناسب لنظام التشغيل الخاص بك (Windows, macOS, Linux).
- قم بتشغيل الملف الذي قمت بتنزيله واتبع تعليمات التثبيت.

### الخطوة 2: إعداد المشروع على جهازك

#### 1. فك ضغط ملف المشروع:
- بعد تنزيل ملف `arabic-academy.zip`، قم بفك ضغطه في أي مكان على جهاز الكمبيوتر الخاص بك (على سبيل المثال، على سطح المكتب أو في مجلد المستندات). سيؤدي ذلك إلى إنشاء مجلد باسم `arabic-academy`.

#### 2. فتح مجلد المشروع في محرر الأكواد:
- افتح برنامج Visual Studio Code.
- من القائمة العلوية، اختر `File` (ملف) ثم `Open Folder...` (فتح مجلد...).
- تصفح إلى المجلد الذي قمت بفك ضغطه للتو (المجلد `arabic-academy`) واختاره ثم انقر على `Select Folder` (تحديد مجلد).

#### 3. فتح Terminal (الطرفية) داخل VS Code:
- داخل Visual Studio Code، من القائمة العلوية، اختر `Terminal` (الطرفية) ثم `New Terminal` (طرفية جديدة).
- ستفتح نافذة طرفية في الجزء السفلي من VS Code، وستكون موجهة تلقائيًا إلى مجلد مشروعك (`arabic-academy`).

#### 4. تثبيت تبعيات المشروع:
في نافذة Terminal التي فتحتها للتو، اكتب الأمر التالي واضغط Enter:

```bash
npm install
```

انتظر حتى يكتمل التثبيت. قد يستغرق هذا بعض الوقت (عدة دقائق) حسب سرعة اتصالك بالإنترنت وقوة جهازك. سترى الكثير من النصوص تظهر في Terminal.

#### 5. إعداد ملفات البيئة (`.env.local`):
- في شريط الملفات على يسار VS Code، ابحث عن ملف باسم `.env.example` وافتحه.
- قم بنسخ كل المحتوى الموجود داخل هذا الملف.
- الآن، قم بإنشاء ملف جديد في نفس المجلد (جذر المشروع) وقم بتسميته `.env.local`.
- الصق المحتوى الذي نسخته من `.env.example` في ملف `.env.local`.

**ملاحظة هامة:** هذا الملف يحتوي على متغيرات البيئة. لكي يعمل الموقع بكامل وظائفه (مثل تسجيل الدخول والدفع)، ستحتاج إلى استبدال القيم الوهمية (مثل `your_supabase_url` أو `pk_test_test`) بالقيم الحقيقية التي تحصل عليها من حساباتك في Supabase و Stripe. إذا كنت تريد فقط تصفح الموقع بدون وظائف تسجيل الدخول والدفع، يمكنك تركها كما هي مؤقتًا.

### الخطوة 3: تشغيل الموقع

#### 1. تشغيل خادم التطوير:
في نفس نافذة Terminal داخل VS Code، اكتب الأمر التالي واضغط Enter:

```bash
npm run dev
```

انتظر قليلاً. سترى رسالة في Terminal تشير إلى أن الخادم قد بدأ، وعادة ما تكون هناك روابط مثل `http://localhost:5173`.

#### 2. فتح الموقع في المتصفح:
- افتح متصفح الويب المفضل لديك (Chrome, Firefox, Edge).
- في شريط العنوان، اكتب أو الصق الرابط الذي ظهر لك في Terminal (عادةً `http://localhost:5173`) واضغط Enter.
